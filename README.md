# section-hero-project

Hero section for **DodzWORKZ Cloud Storage Solutions LLC** (ACT-05), built from my Figma design with HTML and CSS only.

- `index.html` – page structure (header with nav `ul`/`li`, hero with `div` and `span`)
- `style.css` – Flexbox (header, buttons), CSS Grid (hero layout), responsive rules
- `assets/` – logo, settings icon and hero image exported from Figma

Open `index.html` in a browser to view.
